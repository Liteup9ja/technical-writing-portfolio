# Telegram Commands

DGAV provides Telegram commands that allow users to interact with Dangeaky Alert Vitals and access different features.

---

## Available Commands

| Command         | Purpose                                 |
| --------------- | --------------------------------------- |
| `/start`        | Start or restart interaction with DGAV  |
| `/feature`      | View available features                 |
| `/alert`        | Access alert-related functionality      |
| `/subscription` | View or manage subscription information |
| `/plans`        | View available plans                    |

---

## `/start`

Use `/start` to begin interacting with the DGAV bot.

```text
/start
```

The bot will respond with the available options or instructions for your account.

You can also use `/start` again if you need to restart the interaction.

---

## `/feature`

Use `/feature` to view the features available through DGAV.

```text
/feature
```

The features displayed may depend on the current DGAV configuration and your account access.

---

## `/alert`

Use `/alert` to access alert-related functionality.

```text
/alert
```

This command can be used to interact with the alert functionality provided by DGAV.

---

## `/subscription`

Use `/subscription` to access subscription-related information.

```text
/subscription
```

Depending on the current DGAV configuration, this may provide information about your subscription or available subscription options.

---

## `/plans`

Use `/plans` to view available plans.

```text
/plans
```

The plans and features available may change as DGAV evolves.

---

## Command Usage Tips

When using DGAV commands:

1. Send the command directly in the DGAV Telegram conversation.
2. Include the `/` before the command name.
3. Wait for the bot's response before sending another command when an interaction is in progress.
4. Follow any instructions provided by the bot.
5. If a command does not work as expected, review the [Troubleshooting](troubleshooting.md) guide.

---

## Command Reference

For quick reference:

```text
/start
/feature
/alert
/subscription
/plans
```

These commands provide the main entry points for interacting with DGAV through Telegram.
