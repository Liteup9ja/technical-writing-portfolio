# Bot Setup

This guide explains the basic setup required to begin interacting with Dangeaky Alert Vitals (DGAV) through Telegram.

DGAV uses Telegram direct messages to deliver trading alerts and provide access to bot features.

---

## Requirements

Before setting up DGAV, make sure you have:

* An active Telegram account.
* Access to the DGAV Telegram bot.
* A Telegram account that can receive direct messages from the bot.

---

## Open the DGAV Bot

Open Telegram and locate the DGAV bot.

Open the bot conversation to begin interacting with DGAV.

---

## Start the Bot

Send the following command:

`/start`

Starting the bot begins the interaction between your Telegram account and DGAV.

Follow any instructions returned by the bot.

---

## Explore Available Features

After starting the bot, you can use the available commands to explore DGAV.

The main commands include:

| Command         | Purpose                                   |
| --------------- | ----------------------------------------- |
| `/start`        | Start or restart interaction with the bot |
| `/feature`      | View available features                   |
| `/alert`        | Access alert-related functionality        |
| `/subscription` | Access subscription information           |
| `/plans`        | View available plans                      |

The exact options presented by the bot may depend on the current DGAV configuration.

---

## Subscription Setup

If access to certain DGAV features requires a subscription, use:

`/subscription`

to view subscription-related information.

You can also use:

`/plans`

to view the available plans.

Follow the instructions provided by the bot for any subscription-related action.

---

## Confirming Setup

After starting the bot and completing any required account or subscription steps, you can begin using DGAV.

You should be able to:

* Access available bot features.
* View alert-related options.
* Review subscription information.
* View available plans.
* Receive eligible trading alerts through Telegram direct messages.

---

## Receiving Alerts

DGAV sends triggered trading alerts directly to your Telegram DM.

The alert may include:

* Price
* Alert trigger
* Conditions that were met
* Additional alert details

The exact information depends on the alert generated by DGAV.

---

## Setup Checklist

Use this checklist to confirm that your DGAV setup is ready:

* [ ] Telegram account is active.
* [ ] DGAV bot is accessible.
* [ ] `/start` has been sent.
* [ ] Available features have been reviewed.
* [ ] Subscription status has been checked if applicable.
* [ ] Available plans have been reviewed if applicable.
* [ ] Telegram is able to receive messages from DGAV.
